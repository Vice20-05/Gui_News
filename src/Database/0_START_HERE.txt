WHAT WE ARE BUILDING
--------------------
The program will:
  1. read the list of news websites from RSS.json,
  2. download each website's news feed from the internet (https),
  3. save the websites and articles in a SQLite file (news.db),
     skipping anything that is already saved,
  4. show the articles in the GUI with: title, description, date,
     source, link and LANGUAGE.

   RSS.json --> JsonReader --> RssXmlParser --> NewsDatabase --> GUI
   (list of     (reads the     (downloads the   (saves in       (shows the
    websites)    list)          news)            news.db)        news)

THE ORDER TO DO IT IN
---------------------
Do the files in this order. Each step builds on the one before it.

  Step 0  (this file)        pom.xml change
  Step 1  1_RssArticle.txt   REPLACE  src/DataHandle/RssArticle.java
  Step 2  2_RssXmlParser.txt NEW FILE src/Database/RssXmlParser.java
  Step 3  3_NewsDatabase.txt NEW FILE src/Database/NewsDatabase.java
  Step 4  4_RssUpdater.txt   NEW FILE src/Database/RssUpdater.java
  Step 5  5_GUI.txt          REPLACE  src/GUI.java

Tip: type the code yourself instead of copy/pasting. You learn a lot more.
After each step, build the project (VS Code: it shows red errors right away)
and fix any typos before going to the next step.


STEP 0 - Add SQLite to pom.xml
------------------------------
Put this inside <dependencies> ... </dependencies>, next to gson:

        <dependency>
            <groupId>org.xerial</groupId>
            <artifactId>sqlite-jdbc</artifactId>
            <version>3.46.1.3</version>
        </dependency>

Without this, Java cannot open SQLite files and you get the error:
"No suitable driver found for jdbc:sqlite:news.db"

(.gitignore already has "news.db" and "target/" in it, so the database
file and build files will not be uploaded to GitHub. Nothing to do there.)


WHAT ABOUT Sqlink.txt?
----------------------
Sqlink.txt is the small practice version: it ONLY saves the websites
(table "websites"). The files 1-5 are the full version: websites AND
articles (tables "sources" and "articles").
Good plan: do Sqlink.txt first to practise, then do steps 1-5.
In the end you only need the full version, so you can delete SqLink.java.


HOW TO RUN AT THE END
---------------------
Run Main.java from the project root folder (where RSS.json is).
- The window opens right away and says "Loading news...".
- In the terminal you see lines like "Info Mures: 10 new articles".
- After a few seconds the list fills with articles.
- Run it again: the terminal says "0 new articles" for websites
  that have nothing new. That means the duplicate check works.


IF SOMETHING GOES WRONG
-----------------------
"No suitable driver found"          -> you skipped Step 0.
"NoSuchFileException: RSS.json"     -> run from the project root folder.
"package Database does not exist"   -> the files must be in src/Database
                                       and start with: package Database;
"Skipped <website>: ..."            -> that website is down or you have
                                       no internet. The others still work.
Old news.db gives strange errors    -> delete news.db and run again.
                                       It is recreated automatically.
