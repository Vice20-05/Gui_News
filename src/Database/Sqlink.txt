============================================================
 Sqlink.txt  -  Linking RSS.json with a SQLite database
============================================================

WHAT THIS DOES (in simple words)
--------------------------------
1. Reads the list of news websites from RSS.json
   (it uses the JsonReader class that already exists in src/DataHandle).
2. Saves each website in a small database file called news.db.
3. If a website is already saved, it is SKIPPED (no duplicates).
4. Prints everything that is in the database, so you can check it.

   RSS.json  --->  JsonReader  --->  SqLink  --->  news.db
   (the list)      (reads it)       (saves it)    (the database)

WORDS YOU WILL SEE
------------------
- SQLite:   a database that is just ONE file (news.db). No server needed.
- JDBC:     Java's built-in way to talk to databases.
- Table:    like an Excel sheet. Rows = websites, columns = id, name, url.
- SQL:      the language we use to talk to the database
            (CREATE TABLE, INSERT, SELECT).
- UNIQUE:   the database refuses two rows with the same url.
- INSERT OR IGNORE: "add this row, but if it breaks UNIQUE, just skip it".
            This is how "if it's already there, ignore it" works.
- ? marks:  placeholders filled in with setString(). Safer than
            "..." + name + "..." because it stops SQL injection.
- try ( ... ): "try-with-resources". Java closes the connection for you
            automatically when the block ends.


============================================================
 STEP 1 - Add SQLite to pom.xml
============================================================
Put this inside <dependencies> ... </dependencies>, next to gson:

        <dependency>
            <groupId>org.xerial</groupId>
            <artifactId>sqlite-jdbc</artifactId>
            <version>3.46.1.3</version>
        </dependency>

Without this, Java does not know how to open a SQLite file and you get:
"No suitable driver found for jdbc:sqlite:news.db"

 STEP 2 - Create the file  src/Database/SqLink.java

Copy everything between the two lines below into that file.

package Database;

import DataHandle.JsonReader;
import DataHandle.RssSource;

import java.io.IOException;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.List;

// SqLink = the "link" between RSS.json and the SQLite database.
// It reads the websites from RSS.json and saves them in news.db.
// If a website is already in the database, it is skipped.
public class SqLink {

    // The database file. SQLite creates it automatically if it does not exist.
    private static final String DATABASE_URL = "jdbc:sqlite:news.db";

    // Open a connection (a "phone line") to the database.
    public static Connection connect() throws SQLException {
        return DriverManager.getConnection(DATABASE_URL);
    }

    // Create the "websites" table if it is not there yet.
    // UNIQUE on url means the same website can never be saved twice.
    public static void createTable() throws SQLException {
        String sql = "CREATE TABLE IF NOT EXISTS websites ("
                + "id INTEGER PRIMARY KEY AUTOINCREMENT, "
                + "name TEXT NOT NULL, "
                + "url TEXT NOT NULL UNIQUE)";

        try (Connection conn = connect();
             Statement stmt = conn.createStatement()) {
            stmt.executeUpdate(sql);
        }
    }

    // Add one website. If the url is already in the table, SQLite ignores it.
    // Returns true if it was added, false if it was already there.
    public static boolean addWebsite(String name, String url) throws SQLException {
        // The ? marks are filled in below. This is safer than gluing strings together.
        String sql = "INSERT OR IGNORE INTO websites (name, url) VALUES (?, ?)";

        try (Connection conn = connect();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
            stmt.setString(1, name);
            stmt.setString(2, url);
            int rowsAdded = stmt.executeUpdate(); // 1 = added, 0 = ignored
            return rowsAdded == 1;
        }
    }

    // Read every website from RSS.json and put it in the database.
    public static void loadFromJson(String jsonPath) throws IOException, SQLException {
        JsonReader reader = new JsonReader();
        List<RssSource> sources = reader.readSources(jsonPath);

        for (RssSource source : sources) {
            boolean added = addWebsite(source.getName(), source.getUrl());
            if (added) {
                System.out.println("Added:   " + source.getName());
            } else {
                System.out.println("Skipped: " + source.getName() + " (already in database)");
            }
        }
    }

    // Print every website that is saved in the database.
    public static void printWebsites() throws SQLException {
        String sql = "SELECT id, name, url FROM websites";

        try (Connection conn = connect();
             Statement stmt = conn.createStatement();
             ResultSet rows = stmt.executeQuery(sql)) {
            // rows.next() moves to the next row; it returns false when there are no more.
            while (rows.next()) {
                System.out.println(rows.getInt("id") + ". "
                        + rows.getString("name") + " -> "
                        + rows.getString("url"));
            }
        }
    }

    // Run this to test the link on its own.
    public static void main(String[] args) {
        try {
            createTable();
            loadFromJson("RSS.json");
            printWebsites();
        } catch (IOException | SQLException e) {
            System.out.println("Something went wrong: " + e.getMessage());
        }
    }
}

Second run - nothing is added again:

    ...

If you add a new website to RSS.json, only that one says "Added".


============================================================
 HOW EACH METHOD WORKS (short)
============================================================
connect()       Opens the news.db file. Creates it if it is missing.
createTable()   Makes the "websites" table. "IF NOT EXISTS" means it is
                safe to run every time.
addWebsite()    Saves one website. Returns true if it was new,
                false if it was already there.
loadFromJson()  Reads RSS.json with JsonReader and calls addWebsite()
                for each website.
printWebsites() SELECTs all rows and prints them. rows.next() moves to
                the next row and returns false when there are no more.
main()          Runs the three steps in order, so you can test it alone.


============================================================
 COMMON ERRORS
============================================================
"No suitable driver found"   -> you skipped Step 1 (pom.xml).
"NoSuchFileException RSS.json" -> run it from the project root folder.
"package DataHandle does not exist" -> SqLink.java must be in src/Database
                                and start with: package Database;
